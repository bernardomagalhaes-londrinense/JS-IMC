# JS-IMC
Esse script calcula o IMC com variáveis. Alterem os números para verem como fica o seu!
# Como usar?
É necessário ter a extensão Code Runner no VS Code para usar sem navegador. Depois, clique no botão de executar e você verá o código rodar!
# Como personalizar?
As variáveis "Peso" e "Altura" estão no começo do projeto. Colocar o número assim: 0.0 e não 0,0. Por questões de compatibilidade. O resto deixar intacto.
